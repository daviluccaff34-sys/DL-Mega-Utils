# Auto Layout Gen
O perfil combina dificuldade, tempo, sincronização, tipos de trigger e drops. O gerador atual cria somente um plano abstrato de segmentos para validar as escolhas e a lógica inicial.

Ainda não cria objetos no nível nem produz uma fase jogável. A próxima integração deverá converter os segmentos em objetos reais do Geometry Dash usando as APIs do editor, com pré-visualização e opção de desfazer.
